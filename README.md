## 視覺導覽與核心功能

### 1. 桌面頂部靈動島 · 流體交互
![桌面頂部靈動島](showcase/01-overview-hero.png)
- **原生流體動態島交互**：基於非線性減速曲線（Fluid Spring Ease-Out），展開與收合平滑自然；座標鎖定置中，避免跨幀抖動。
- **膠囊與展開雙態自由變換**：滑鼠移入展開完整數據儀表板；收合狀態化身極簡膠囊，即時掌握關鍵模型額度、微氣象與時間。
- **智慧避讓與劇院模式**：偵測全螢幕遊戲、看電影或瀏覽器頂部自動避讓；全透明穿透邊界，不阻礙底層應用正常操作。

---

### 2. 多模型 AI 用量監控 · 即時配額掌握
![多模型 AI 用量監控](showcase/02-ai-quota-monitor.png)
- **支援主流客戶端**：支援 Codex、Google Antigravity 與 Claude 官方 Windows 桌面版。
- **雙週期配額條**：區分「5 小時短週期」與「每週長週期」剩餘額度，用量百分比與圖形進度條同步對齊。
- **重置倒數提示**：動態計算下一次重置時程，標註「今天 下午 03:32」或「10月25日」，掌握重置節奏。
- **Token 消耗追蹤**：記錄目前對話累計 Token 數量，本機快速解析，無額外伺服器網路開銷。

---

### 3. 三大靈動伴侶角色 · 五階用量動態
![三大靈動伴侶角色](showcase/03-pixel-companions.png)
- **三大角色自由切換**：
  - **貓咪 (Cat)** · 經典暖橘（換色時保留琥珀金大圓眼與粉嫩鼻頭）
  - **赤狐 (Fox)** · Antigravity 蔚藍
  - **貓頭鷹 (Owl)** · 曜石銀灰（換色時保留樹枝木紋與自然綠葉）
- **情緒階梯粒子特效**：
  - **充足 $\ge 60\%$**：四角星芒閃爍升騰、貓頭鷹枝頭眨眼
  - **留意 20–59%**：頭頂閃爍驚嘆號警戒
  - **偏低 1–19%**：疲憊冷汗珠滑落
  - **用盡 0%**：趴臥休眠動態 Zzz 夢境升騰
  - **未知／待機**：靜態灰階待命
- **主題配色與自訂 HEX 染色**：支援蔚藍、翡翠綠、櫻花粉、暖橘、曜石銀灰等經典色票，亦可直接輸入自訂 HEX 色碼即時像素重染色。

---

### 4. 在地微氣候 · 個人行事曆同步
![高解析在地微氣候](showcase/04-weather-schedule.png)
- **微氣候數值預報**：自動偵測本地 IP 經緯度，整合數值預報呈現氣溫與體感溫度。
- **降雨提示門檻**：降雨機率 $\ge 35\%$ 且預估降雨量 $> 0.1\text{ mm}$ 時觸發降雨警示，晴天不誤報，具備帶傘參考價值。
- **行事曆與桌面便利貼**：支援 Google Calendar iCal 雙向排程同步、活動倒數，並提供桌面便箋記錄功能。

---

### 5. 個人化定制 · 多語系與多螢幕適配
![高度個人化定制](showcase/05-customization-settings.png)
- **12 國在地化語言**：支援繁體中文（台灣）、簡體中文、英語、日本語、韓語、德語、法語、西班牙語等 12 款語言，即時熱切換。
- **多螢幕與避讓設置**：可指定主副顯示器吸附，支援全螢幕自動淡出與遊戲避讓，維持專注體驗。

## 快速建置 (Build from Source)

本專案使用 Windows 原生 .NET Framework 4.8 編譯，無需安裝任何龐大依賴（如 Node.js、Python 或 Visual Studio 大型工作負載）。

### 建置指令
以 PowerShell 開啟專案根目錄，執行：
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
腳本將自動調用系統內建之 `csc.exe` 進行編譯與最佳化，生成可獨立運行的 `TokenIsland.exe`。

## 隱私與安全保證 (Privacy & Security)

- **本地優先架構**：所有使用者自訂偏好設定、Google Calendar 私人 iCal 網址、日程快取與桌面便箋資料，**全數隔離儲存於本機 `data/` 目錄中**。
- **零數據上傳**：本專案不設任何第三方統計伺服器，絕不收集或上傳使用者之聊天文字、個人憑證、行事曆日程或釘選筆記。
- **開源透明**：全專案原始碼開放審查，所有網路調用僅限官方公開端點（Open-Meteo 氣象數值預報、使用者自行設定之 Google iCal 私人網址）。
