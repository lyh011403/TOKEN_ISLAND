Token Island · NotchNook — Windows 旗艦級頂部動態島
版本 0.4.0 · 2026-10-15

開始使用
雙擊 TokenIsland.exe。動態島頂部黑膠囊常駐於螢幕頂端正中央。
Windows 10 / 11 x64，使用 Windows 原生 .NET Framework 4.8；不需安裝 Node、Python 或額外龐大依賴。

NotchNook 核心功能與操作
• 頂部黑膠囊（Notch Capsule）：平常常駐於螢幕頂端中央，播放音樂時自動顯示迷你專輯封面、曲名與綠色律動波形；未播放時顯示精緻 Nook 膠囊與 AI 服務微狀態。
• 平滑向下跳窗展開（Hover Expand）：滑鼠移入頂部黑膠囊 120ms 自動向下滑出展開為寬幅大卡片（530px 寬）；滑鼠移出約 0.75 秒自動縮回膠囊。
• 固定展開（Pin）：點擊右上角 ◇ 可鎖定展開，再次點擊 ◆ 取消鎖定。
• 雙分頁標籤切換（Tabs）：
  - [🎵 Nook]：
    * 左側全域媒體播放器：接入 Windows 10/11 GSMTC，即時取得 Spotify、Apple Music、Chrome、Edge、網易雲等播放中曲目、歌手、專輯封面與播放/暫停/切歌控制。
    * 右側日曆與日程：顯示當前月份大字、當週 5 天日期滑軌（今日日期以深天藍高亮藥丸膠囊突顯）、今日待辦摘要，點擊可快速開啟 Windows 行事曆。
  - [📂 Tray]（檔案暫存架 Drop Shelf）：
    * 將任何檔案、圖片、資料夾直接拖入動態島，自動展開並收錄於暫存架。
    * 暫存架呈現水平微型膠囊捲軸，顯示檔案關聯圖標、檔名與大小。
    * 支援按住卡片直接拖出（Drag & Drop）至桌面、資料夾或通訊軟體，雙擊直接開啟檔案，支援一鍵清空全部暫存。
  - [🐱 AI Hub]：完整保留既有 Codex、Antigravity、Claude 的用量額度進度條、重置倒數、動態像素貓咪與掉落動畫（防退行保護）。

傳統浮窗操作
• 點擊浮窗才展開；滑鼠碰到不會展開，移出約 0.7 秒自動收合。
• 按住浮窗的空白處、標題或數字區拖曳：自由移動；按鈕與捲軸保留原本操作。
• 頂部邊緣吸附（靈動島模式）：拖曳至螢幕最上方邊界（60px 內）自動無縫貼齊，頂部外距自動重設為 0，完全吻合螢幕頂緣 0px 無縫隙；浮窗寬度自動依啟用服務數量自適應收縮。
• 頂部自動收展（Auto-hide）：置於螢幕頂端閒置 2.5 秒後，浮窗會自動向上平滑收起，僅露出一條 14px 微型膠囊指示條；點擊頂端指示條後，才平滑向下滑出並展開。
• 拖到螢幕左／右邊緣放開：自動吸附成直立小膠囊，仍顯示服務與剩餘比例。
• 貼邊後點擊：向螢幕內側展開；拖離邊緣：恢復自由浮動。
• ≡ 選單提供「貼齊頂部」「貼齊左側」「解除貼邊」「貼齊右側」一鍵對齊。
• 右上角 ◇：固定展開；再次取消後，滑鼠移出就會收合。
• 視窗透明度調整：可在 ≡ 選單快速切換 100%（不透明）、90%（推薦）、80%、65% 等半透明檔位，與桌面完美融合。
• Token 總結掉落貓咪動畫：Codex、Antigravity 每輪對話完成後，僅跳出一次本輪累計消耗的 Token 總量；生成中與額度變動時不跳出，啟動程式也不重播過往總結。Antigravity 總量加總本輪各次模型呼叫的輸入、輸出與快取 Token；不代表付費金額。Claude 目前未提供可辨識的完成訊號，因此暫不自動跳出總結；手動動畫測試仍可使用。
• 掉落動畫自訂設定：可於 ≡ 選單自由開啟／關閉動畫、調整動畫縮放大小（75%、100%、125%、150%）以及調整出現位置（跟隨浮窗、頂部置中、頂部右側），並提供即時測試按鈕。
• 記住位置、貼邊方向、縮放比例、透明度與服務開關；依所在螢幕的工作範圍避開工作列。
• 不透背景的像素邊框、分段進度條、平滑展開動畫；遵循 Windows 的停用動畫設定。
• ≡ 或按右鍵：個別開關 Codex、Antigravity、Claude。
• 自由縮放顯示比例：按住 Ctrl + 滑鼠滾輪可隨意微調（70%–200%），或在 ≡ 選單點選 80% / 100% / 125% / 150%。
• 選單可以設定縮放比例、視窗透明度、呼吸燈、動物動畫、減少動態、低額度提醒、登入 Windows 時啟動。
• 右下角通知區圖示：雙擊顯示，右鍵可隱藏或結束。
• 若啟動後找不到，請查看 Windows 通知區隱藏圖示。
• Codex、Antigravity 與 Claude 皆套用專屬狀態動態貓咪角色。
• 收合列百分比是該服務已知、尚未到期額度中的最低剩餘值。點擊看各個區間。
• 星號 *：資料超過 5 分鐘或連線失敗，屬於上次資料。
• —：沒有已驗證的可用數字，不代表 0% 或 100%。

像素動物與狀態
• ≥60%（充足）：高舉問號尾巴，輕快踏步、神采奕奕。
• 20–59%（留意）：壓低重心成潛伏姿勢，雙耳轉動、專注戒備；在每輪循環第一幀頭頂閃現經典像素「！」驚嘆號警戒特效。
• 1–19%（偏低）：母雞蹲飛機耳，半瞇眼打盹打呵欠。
• 0%（用盡）：徹底軟爛化開成貓餅，肚皮朝天閉眼休眠，頭頂伴隨動態升騰 ZZZ 睡著特效。
• 未取得額度、資料過期或查詢失敗：半透明灰階休眠姿態加問號標註；不能解讀成額度已用盡。
• 動物狀態以該服務已知、未到期額度中的最低剩餘比例計算，動作無限循環播放。
• 貓咪毛色可單獨指定：可在 ≡ 選單分別為 Codex、Antigravity、Claude 單獨指定暖橘、蔚藍、紫羅蘭、翡翠綠、櫻花粉或曜石灰。
• 呼吸燈約 3 秒明暗循環（貓咪本體柔和呼吸律動，無背後底框遮擋）。
• 呼吸燈與動物動畫可各別關閉；「減少動態」會停止所有動態循環並維持靜態畫面。
• 新版保留三個服務，已移除 ChatGPT 一般聊天卡片。
• 浮窗保留你原有的顯示開關；若看不到某服務，請在 ≡ 裡啟用。
• 收合約 274×60、展開最多 324×408、貼邊寬 60（含外圍空白，Windows 縮放會影響螢幕像素）。

目前資料來源與限制

1. Codex：已實測接入
每 10 秒唯讀掃描目前 Windows 使用者的 .codex/sessions 紀錄（或 CODEX_HOME/sessions）。
讀取最近活動紀錄中的 token_count，顯示短期／每週額度及重置時間。
Token 數是「最近活動對話的累計」，不是全部帳號總量，也不是剩餘 Token。
此來源在 Codex 產生新用量事件時更新；沒有新事件時保留原時間，不假裝取得新的伺服器資料。
只在記憶體解析紀錄，不複製聊天文字到本程式資料夾。

2. Antigravity：已實測接入 14 個模型的額度
約每 10 秒查詢正在執行的本機 Antigravity language server；對話紀錄變動時也會更新。
請先登入並開啟 Antigravity；本工具不啟動生成工作，不消耗生成 Token。
使用唯讀 GetUserStatus，本機連線驗證值只在記憶體使用，不寫入檔案。
這是版本相依的本機介面，Antigravity 更新後可能需要調整。
顯示剩餘百分比與重置倒數；卡片 Token 數為最近一次模型呼叫用量（含快取），不是帳號累計。對話結束提示則加總本輪模型呼叫的用量。
以唯讀方式讀取本機 conversations SQLite／WAL 紀錄；只有最終回覆完成且沒有工具呼叫時才跳出總結，不以閒置秒數猜測完成。
有些模型可能共用額度，相同比例不表示每個模型各有獨立存量。
卡片會彙整同系列、相同比例／時間的模型；按「查看全部」可看各模型明細。
Antigravity 裡的 Claude 額度不等於你在 Claude 官方訂閱的額度。

3. Claude：已支援 Claude 官方 Windows 桌面應用程式（Claude for Windows）
自動偵測本機正在運行的官方 Claude Windows 桌面應用程式（MSIX / WindowsApps 封裝及標準版）。
讀取本地快取（config.json、plan-usage-history.json），自動同步連線狀態與登入帳號資訊。
當 Claude 桌面應用程式啟動並連線時，貓咪即時呈現活躍狀態；若未啟動，呈現離線灰階狀態。
若官方桌面版回報額度用盡或日誌限額，自動切換為 0%（觸發癱倒流體貓餅 + ZZZ 睡眠動態特效）。
可於卡片點選「開啟 Claude 桌面版」直接喚起或檢查官方桌面版連線狀態。
同時相容 Claude Code CLI 狀態列（--claude-statusline）橋接資料。

已有自訂 statusLine 的手動接入
保留原設定，在你原本的狀態列腳本收到 JSON 後，將同一份 stdin JSON 額外傳給：
  "完整路徑/TokenIsland.exe" --claude-statusline
將此命令輸出丟棄，再輸出你原本的狀態列。
亦可選擇自行修改 ~/.claude/settings.json 的 statusLine.command；命令路徑需雙引號。
請勿把你的登入憑證貼到任何設定檔或聊天中；此橋接不需要 API key。
解除接入：還原備份的 settings.json，或僅移除本工具新增的 statusLine 欄位。

資料與安全
設定及測試結果儲存在程式旁的 data/。程式不向第三方伺服器上傳統計或對話。
只有按「登入 Windows 時啟動」才寫入當前使用者的 Run 登錄值。
程式不自動安裝自己、不修改 AI 程式、不啟動 AI 任務。
Antigravity HTTPS 的本機自簽憑證例外僅適用該次固定 127.0.0.1 要求，不影響其他連線。

移除
若曾啟用開機啟動，先從選單取消。
若曾連接 Claude，先還原其 statusLine 設定。
從通知區結束程式，再刪除這個資料夾即可。

原始碼與驗證
src/：完整原始碼。TokenIsland.cs 為資料與介面，PixelUi.cs 為像素動物與呼吸動畫。
build.ps1：使用 Windows 內建 C# 編譯器重新產生 exe。
TokenIsland.exe --self-test：驗證數值解析與額度語意，結果存入 data/test-results.json。
TokenIsland.exe --diagnose：僅讀取資料，摘要存入 data/diagnostics.json（不含憑證）。
